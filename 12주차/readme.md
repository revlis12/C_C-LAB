[파일]

FILE 구조체와 파일선언 : 
  #include <Stdio.h>
  FILE *filename; // 파일 구조체 변수 선언
-> FILE구조체를 사용하여 파일을 다루기 위한 포인터 변수를 선언한것
-> FILE은 파일 처리를 위해 표준 라이브러리에 미리 정의된 자료형

파일 열기 : fopen() (r,w,a,r+,w+,a+)
파일 닫기 : fclose()
문자 단위 파일 처리 : fgetc() : 파일 포인터가 가리키는 대상 파일에서 1바이트씩 읽어 int형으로 반환하며 오류 발생하거나 파일의 끝을 만나면 EOF를 반환, fputc()
