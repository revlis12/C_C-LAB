[재귀 함수] - 직접적 또는 간접적으로 자신을 호출하는 함수 (LIFO)

[함수의 연결]
-내부연결 : 파일
-외부연결

[배열]
int a[10] == int=4byte -> 총 40byte
a == 배열의 시작주소

int a[10] = {1, 2, 3, 4, 5}
           [a,a+1,a+2,a+3,a+4]
           [0, 1, 2, 3, 4]

[배열 선언]
scanf("%s", a) a[0] -> 문자열
scanf("%d" or "%c", &a[0])

[범위] - int valid_range[5]; 의 유효범위는 0~4
[초기화] - 자료형 배열명[요소개수] = { 값1, 값2, 값3 ..., 값n}

[배열과 함수]
배열과 매개변수 : 배열의 모든 요소를 한꺼번에 함수에 전달 가능

[배열의 활용]
배열과 최댓값 : 배열의 최댓값은 데이터의 범위를 파악하는데 중요한 요인
int max_value = findMax(numbers, 10); // 최댓값을 찾는 함수 호출

버블 정렬 : 가장 인접한 두 요소부터 가장 멀리있는 요소까지 비교후 위치를 바꾸는 작업을 반복해 최댓값이 마지막 위치에 자리하는 방식
