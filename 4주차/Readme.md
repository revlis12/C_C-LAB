[함수] - 동일한 입력에 대해 같은 작업을 여러 번 수행할 수 있다

[형식] - 함수 정의
    반환형 함수명 (매개변수1, 매개변수2) {
    // 함수 몸체
    // 실행할 문장 }                                     ===> 반환형 ( 타입을 써주기 or 타입이 따로 없다면 void)
                                                             매개변수에도 받는 타입을 선언해야함
      - 함수 선언 - 메인보다 상단에 함수 선언을 쓰고, 함수 정의는 중괄호 안에서 아무 블록이나 해도 상관없다.
      - 함수 호출 - 함수이름();

 - 함수의 형태
 - 매개 변수와 반환값이 없는 함수
 - 매개 변수가 없고 반환값이 있는 함수
 - 매개변수와 반환값이 있는 함수

[rand] - 랜덤 숫자
rand() 100%; == 0부터 99 사이의 값을 반환
1 + rand() % 100 == 1부터 100 사이의 값을 반환

[srand] - rand() 함수에 의해 생성되는 난수 시퀀스의 시드를 설정하는데에 사용
=> 시드를 설정하면 rand()함수가 의사 난수를 생성할 때 시드값을 기준으로 균등하게 분포된 난수인 난수 시퀀스 시작

[번수]
-지역 변수 (매개변수) : 변수명이 동일해도 선언 위치가 다르다면 각기 다른 변수로 인식
  => 지역 변수가 선언된 블록의 실행이 시작될 때 스택 메모리에 지역변수가 할당
  => 전역 변수와 달리 함수 호출이 종료되면 함수 내의 지역변수 자체가 소멸
-전역 변수

[변수의 연결] - 변수의 범위, 수명, 파일의 변수 접근 가능 여부 
- 내부 연결 : static - 파일 내부에서만
- 외부 연결 : 다른 소스 파일에서 extern 키워드 사용해 접근

[변수의 지속 기간]
- 정적할당 : 프로그램의 실행 종료 시점에 메모리에서 해제
  => 전역 변수 및 ststic 지정자로 선언된 지역변수가 사용된 정적 할당의 예
    int globalVar;  // 전역변수

    void func() {
       static int staticVar; //정적 할당
      } // 프로그램 끝까지 변수의 값 유지

- 자동 할당:: 함수 호출 시 메모리 할당 / 반환 시 메모리에서 해제

[저장 유형 지정자]
- auto 지정자 : 자동 변수, 지역변수
- register 지정자 : 레지스터 변수, CPU의 레지스터에 변수가 저장
- volatile 지정자 : 컴파일러에 의해 변수가 최적화되지 않도록 지시
- ststic 지정자 : 정적 변수로 선언하면 변수가 초기화될 때 메모리에 할당되고, 프로그램 실행 종료까지 유지

[가변 매개변수 함수] : 매개변수 호출 시 매개변수의 개수를 정해두지 않고 다양하게 사용할 때 사용되는 매개변수
- ...(ellipsis)
- va_list : 함수 정의에서 가변 매개변수의 시작
- va_start : 가변 매개변수 목록을 저장하기 위한 자료형
- va_arg : 가변 매개변수 목록에서 시작을 초기화하는 매크로
- va_end : 가변 매개변수 목록에서 다음 인자를 가져오는 매크로
