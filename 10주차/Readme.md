[문자 처리 관련 함수]
isalpha : 알파벳인지 확인
isupper : 대문자인지 확인
islower : 소문자인지 확인
isdigit : 숫자(0~9)인지 확인
isalnum : 알파벳 or 숫자 인지 확인
isxdigit : 16진수에 해당하는지 확인
ispunct : 구두점 문자인지 확인 : 알파벳, 숫자, 공백이아닌 인쇄 가능한(프린터블) 문자를 말함
isprint : 프린터블 문자인지 확인
iscntrl : 제어문자 인지 확인 : 줄바꿈, 탭
isascii : 아스키 문자 집합에 포함되는지 확인
toupper : 소문자를 대문자로
tolower : 대문자를 소문자로
toascii :아스키 코드로 변혼

[문자열 입출력 함수]
gets : 표준입력에서 문자열을 읽어들임
puts : 표준 출력으로 문자열 출력 후 자동으로 줄바꿈 문자를 끝에 추가
fgets : 파일이나 표준 입력에서 문자열을 읽어들이는데, 지정된 크기 -1만큼 또는 줄 바꿈 문자를 만날 때 까지
gputs : 파일이나 표준 출력으로 문자열 출력

[<string.h> 헤더 파일의 정의]
strlen : 문자열 길이 계산
strcpy : 문자열 복사
strncpy : 문자열 복사 : 나머지 부분은 널문자로 채워짐
strmp : 문자열 비교 : str1 과 2크기 비교후 크면 양수 작으면 음수 같으면 0
strncmp : 문자열 비교 : 최대 n개 문자까지만 비교
strcat : 문자열 연결 : 연결 -> 널 문자를 덮어서
strncat : 문자열 연결 : str2의 최대 n개 문자를 str1 끝에 연결
strchr : 문자열 검색 : 첫번째로 나타나는 문자 ch의 위치 바환 못 찾을 경우 null
strstr : 문자열 검색 : 문자열 str1 내에서 부분 문자열 str2가 시작되는 첫번째 위치를 반환
char *strtok : 문자열 분리 

[구조체] - 사용자 정의 자료형 중 하나로, 서로 다른 자료형의 데이터를 하나로 묶는 복합 데이터 형식
(기본 자료형, 파생 자료형, 사용자 정의 자료형)

[이진 탐색]
반으로 쪼개서 탐색 (오름차순이나 내림차순으로 정렬 되어있는 가정)


[배열과 구조체의 차이]
배열 : 하나의 값만 저장할 수 있는 구조라 여러 값 저장 때 사용함
구조체 : 각기 다른 자료형의 데이터를 하나로 활용할 때 용이,
        데이터 조직화에 유용
